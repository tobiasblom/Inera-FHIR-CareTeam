Extension: Kontakt via team

Officiell URL: https://fhir.inera.se/ig/careteam/StructureDefinition/contact-via-team Version: 0.9
Draft per 2026-10-15 Beräkningsbart namn: RIVContactViaTeamExtension

Anger ett team som en fast kontakt kan nås via.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: CareTeam.participant

Usage info

Användningar:

  • Använd denna Extension: Fast kontakt
  • Exempel för denna Extension: CareTeam/ExampleCareManager

Du kan också kontrollera användningar i FHIR IG-statistiken
